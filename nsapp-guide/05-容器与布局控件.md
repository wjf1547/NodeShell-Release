# 第 5 章 · 容器与布局控件

`root` / `card` / `row` / `column` / `space` / `divider`

---

## 5.1 root —— 屏幕容器

每个页面的最外层。提供顶栏标题与整页滚动。

```js
{
  type: 'root',
  props: { title: '我的应用', subtitle: '副标题', scroll: true },
  children: [ /* ... */ ],
}
```

| 字段 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `title` | string | — | 顶栏标题 |
| `subtitle` | string | — | 顶栏副标题 |
| `scroll` | bool | false | 整页可滚动。**不能与 list/grid/tabs 混用** |
| `id` | string | — | 页面标识，用于滚动位置记忆（见 [10.4](10-页面栈与返回.md)） |

### scroll 到底怎么设

```js
// ✅ 短内容，想上下滑
{ type:'root', props:{ scroll:true, title:'关于' }, children:[ ...若干 text/button... ] }

// ✅ 有长列表 —— 不要 scroll，让 list 自己滚
{ type:'root', props:{ title:'文件' }, children:[ { type:'list', props:{ items } } ] }

// ❌ 会崩（Lazy 组件 + verticalScroll = 无限高度约束）
{ type:'root', props:{ scroll:true }, children:[ { type:'list', ... } ] }
```

> 基座 0.1.42+ 对「Lazy 组件放进 scroll 容器」有自动降级防护，不会崩，但**会丢掉你想要的滚动行为**。自己写对。

## 5.2 card —— 卡片容器

最常用的分组容器。带圆角、边框、底色。

```js
{
  type: 'card',
  children: [
    { type: 'text', props: { text: '卡片标题', size: 14, bold: true } },
    { type: 'text', props: { text: '卡片内容', size: 12, color: '#888' } },
    { type: 'button', props: { text: '操作', onClick: 'do' } },
  ],
}
```

**无 props**（不接受任何字段）。

### 嵌套组合

```js
{ type:'card', children:[
  { type:'row', props:{ gap:8 }, children:[
    { type:'icon', props:{ name:'⚠️', size:24 } },
    { type:'column', props:{ gap:4 }, children:[
      { type:'text', props:{ text:'警告', size:14, bold:true } },
      { type:'text', props:{ text:'此操作不可撤销', size:12, color:'#888' } },
    ]},
  ]},
]}
```

## 5.3 row —— 横向布局

### 5.3.1 横向滚动行（0.1.82 起默认行为）

`scroll` 默认 `true`：子节点按**内容宽度**排布，总宽超出屏幕可左右滑动。
适合 chip 标签过多/过长。

```js
{ type:'row', props:{ gap:8 }, children:[
  { type:'chip', id:'c1', props:{ text:'全部',   selected:true,  onClick:'f' } },
  { type:'chip', id:'c2', props:{ text:'音乐',   selected:false, onClick:'f' } },
  { type:'chip', id:'c3', props:{ text:'视频',   selected:false, onClick:'f' } },
  { type:'chip', id:'c4', props:{ text:'文档',   selected:false, onClick:'f' } },
  // 再多也只会横向滚动，不会把按钮挤出屏幕
]}
```

### 5.3.2 均分整行（老行为）

`scroll: false` → 全部子节点**均分整行**（0.1.22 行为）。

```js
{ type:'row', props:{ scroll:false }, children:[
  { type:'button', id:'b1', props:{ text:'取消', onClick:'no', variant:'outlined' } },
  { type:'button', id:'b2', props:{ text:'确定', onClick:'ok' } },
]}
// 两个按钮各占一半宽度
```

### 5.3.3 显式权重 `weights`

`weights` 与 `children` **下标平行**：数字 = weight 份额（填满），`"auto"`/`null` = 按内容排。

```js
{ type:'row', props:{ weights:[1, 'auto', 2] }, children:[
  { type:'text', props:{ text:'弹性', size:12 } },   // 占 1 份
  { type:'button', props:{ text:'固定宽', onClick:'x' } },  // 按内容
  { type:'progress', props:{ value:0.5 } },          // 占 2 份
]}
```

数组短于 children → 缺位按 `auto`。

### 5.3.4 字段表

| 字段 | 值 | 默认 | 说明 |
|---|---|---|---|
| `align` | `top`/`center`/`bottom` | `center` | 垂直对齐 |
| `justify` | `start`/`center`/`end`/`between` | `start` | 水平分布 |
| `gap` | number (dp) | `8` | 子节点间距 |
| `scroll` | bool | `true` | true=横向滚动行；false=均分整行 |
| `weights` | array | — | 每项权重；数字/`"auto"`/`null` |

## 5.4 column —— 纵向布局

```js
{ type:'column', props:{ gap:10 }, children:[
  { type:'input',  id:'a', props:{ placeholder:'第一行', onChange:'in' } },
  { type:'input',  id:'b', props:{ placeholder:'第二行', onChange:'in' } },
  { type:'button', id:'go', props:{ text:'提交', onClick:'go' } },
]}
```

| 字段 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `gap` | number (dp) | 不插间距 | 子节点间距（`column` 只读 `gap`，不支持 align/justify） |

> **root 的默认布局就是纵向排列**，不需要额外包 `column`。`column` 的价值在 `gap`（控制间距）和嵌套到 `row`/`card` 里做竖排。

## 5.5 space —— 空白占位

```js
{ type:'space', props:{ height: 24 } }    // 竖缺口
{ type:'space', props:{ width: 12 } }     // 横缺口（放 row 里）
```

| 字段 | 类型 | 默认 |
|---|---|---|
| `height` | number (dp) | — |
| `width` | number (dp) | — |

**典型用途**：给 fab 留位置，防止它盖住最后一项。

```js
// 列表末尾留出空间，悬浮按钮不遮挡
{ type:'list', props:{ items, footer:[ { type:'space', props:{ height:72 } } ] } },
{ type:'fab', props:{ text:'＋', onClick:'add' } },
```

## 5.6 divider —— 分割线

```js
{ type:'divider' }     // 无 props
```

典型用途：在设置卡片里分隔两组开关。

```js
{ type:'card', children:[
  { type:'switch', id:'s1', props:{ label:'开关一', checked:true, onChange:'sw' } },
  { type:'divider' },
  { type:'switch', id:'s2', props:{ label:'开关二', checked:false, onChange:'sw' } },
  { type:'divider' },
  { type:'button', props:{ text:'清除数据', variant:'text', onClick:'clear' } },
]}
```

## 5.7 accordion —— 折叠面板（0.1.91+）

多个可展开区块，每个区块有标题 + **任意子节点**。FAQ / 设置分组 / 筛选条件都靠它。

```js
{ type:'accordion', id:'faq', props:{
    exclusive: true,              // true = 手风琴模式, 同时只展开一个
    onExpand: 'faqExpand',
    items: [
      { id:'q1', title:'常见问题', icon:'❓', subtitle:'2 条', expanded: true,
        children: [
          { type:'text', props:{ text:'Q: tree 的 children 写在哪?', size:13, bold:true } },
          { type:'text', props:{ text:'A: items[] 里, 不是 node.children。', size:12, color:'#888' } },
        ] },
      { id:'q2', title:'高级设置', icon:'⚙️', expanded: false,
        children: [
          { type:'switch', id:'sw', props:{ label:'开关', checked:true, onChange:'sw' } },
        ] },
    ],
}}

$ui.on('faqExpand', (e) => {
  const n = state.faq.find(x => x.id === e.id);
  if (n) { n.expanded = !!e.expanded; render(); }   // ⚠️ 受控: 必须 render
});
```

| 字段 | 类型 | 说明 |
|---|---|---|
| `items[]` | — | `{id, title, subtitle?, icon?, expanded, children}` |
| `exclusive` | bool | `true` = 同时只展开一个（手风琴模式） |
| `onExpand` | string | 点标题行切换展开，`e.id` + `e.expanded` |

### ⚠️ `children` 在 `items[]` 里，是**节点数组**

这点与 `tree` 正好相反：

| 控件 | `children` 在哪 | 是什么 |
|---|---|---|
| `accordion` | `items[].children` | **节点数组**（走 Node 渲染，可放任意控件） |
| `tree` | `items[].children` | **数据行**（`{id,title,...}`，不是节点） |

## 5.8 布局实战：一个设置页

```js
function renderSettings() {
  $ui.render({
    type:'root', props:{ title:'设置', scroll:true, id:'page-settings' },
    children:[
      // 分组标题
      { type:'text', props:{ text:'━ 播放 ━', size:13, color:'#4FC3F7', bold:true } },
      { type:'card', children:[
        { type:'switch', id:'auto', props:{ label:'自动播放', checked:state.autoPlay, onChange:'sw' } },
        { type:'divider' },
        { type:'slider', id:'vol', props:{ label:'默认音量', min:0, max:100, step:5,
                                            value:state.volume, onChange:'slider' } },
      ]},

      { type:'space', props:{ height:20 } },
      { type:'text', props:{ text:'━ 网络 ━', size:13, color:'#4FC3F7', bold:true } },
      { type:'card', children:[
        { type:'input', id:'srv', props:{ value:state.server, placeholder:'服务器地址',
                                          onChange:'srv' } },
        { type:'divider' },
        { type:'row', props:{ scroll:false, gap:8 }, children:[
          { type:'button', props:{ text:'测试连接', variant:'tonal', onClick:'ping' } },
          { type:'button', props:{ text:'恢复默认', variant:'text',   onClick:'reset' } },
        ]},
      ]},

      { type:'space', props:{ height:20 } },
      { type:'text', props:{ text:'━ 关于 ━', size:13, color:'#4FC3F7', bold:true } },
      { type:'card', children:[
        { type:'text', props:{ text:'版本 ' + $app.version, size:12, color:'#888' } },
        { type:'text', props:{ text:'基座 ' + $shell.version, size:12, color:'#888' } },
      ]},
    ],
  });
}
```

## 5.9 常见错误

| 症状 | 原因 |
|---|---|
| 卡片整张空白 | `children` 写进了 `props.children`（见 [3.2](03-UI树基础.md)） |
| 页面崩/白屏 | `list`/`grid`/`tabs` 放进了 `root scroll:true` |
| 按钮被挤出屏幕点不到 | `row scroll=false` 均分，项太多；改成滚动行或减项 |
| 竖排没有间距 | 忘了 `column props.gap`，root 默认不插间距 |
| fab 盖住最后一项 | 列表 `footer` 里加 `{type:'space',props:{height:72}}` |
