# 第 6 章 · 列表与集合控件

`list` / `grid` / `actions` / `table` / `chart` / `empty`

---

## 6.1 ⚠️ 先看这里：list 不读 children

**这是全文档最重要的一条。**

```js
// ❌ 完全静默丢弃 —— 不报错，只是整块不显示
{ type:'list', props:{ items }, children:[ { type:'actions', ... } ] }

// ✅ actions / header / footer 全写进 props
{ type:'list', props:{ items, actions:[...], header:[...], footer:[...] } }
```

原因：`ListNode()` 里根本没有读 `children` 的分支。你写它不会报错，
只会得到「按钮凭空消失」。**有应用的真实 bug 就是这个**。

基座 0.1.64+ 会在 `$ui.render` 时校验并 warn（调试器 Console 可见），
0.1.67+ 明确提示「list 的外围节点请写 props.header/footer/actions/secondaryActions」。

## 6.2 list —— 卡片列表

### 6.2.1 items[] 全部字段

```js
{
  id: 'f1',                       // 事件回传用（必填，否则点不到具体项）
  title: 'BigBuckBunny.mp4',      // 主标题
  subtitle: '158MB · 10:34',      // 副标题
  icon: '🎬',                     // 左侧图标（emoji 或文字）
  avatar: 'https://.../a.png',    // 左侧头像（与 icon 二选一）
  badge: '新',                    // 右侧小徽标
  right: '128MB',                 // 右侧文字
  more: [                         // 右侧 ⋯ 菜单
    { text: '重命名', onClick: 'ren' },
    { text: '删除',   onClick: 'del' },
  ],
  onClick: 'play',                // 点整行
  onLongClick: 'long',            // 长按整行
}
```

### 6.2.2 最小可用

```js
{ type:'list', props:{
    items: [
      { id:'a', title:'条目 A', onClick:'item' },
      { id:'b', title:'条目 B', subtitle:'带副标题', onClick:'item' },
    ],
}}
```

### 6.2.3 header / footer 冻结栏

`header` / `footer` 是 **props 里的节点数组**，会固定在列表上/下（不随列表滚动）。

```js
{ type:'list', id:'fileList', props:{
    items: files,
    header: [
      { type:'text', props:{ text:'共 ' + files.length + ' 项', size:12, color:'#888' } },
      { type:'divider' },
    ],
    footer: [
      { type:'divider' },
      { type:'actions', props:{ align:'fill', items:[
        { text:'删除', onClick:'del' },
        { text:'重命名', onClick:'ren' },
      ]}},
    ],
}}
```

**⚠️ `root scroll=false` 页面里，`actions`/`fab`/输入栏一律放进 `list` 的 `footer`，
不能与 `list` 平级。**

根因：`root scroll=false` 时渲染器走普通 `Column`，`list` 若与 `actions` 平级，
`list` 拿不到 `weight(1f)`，高度不确定 → 底栏被挤出可视区或点击命中不到。
**一个多页面应用的真机 bug。**

### 6.2.4 actions / secondaryActions 按钮栏

`actions` 是**展示在列表上方的按钮行**，`secondaryActions` 是次要操作行。
两者都是 `props` 里的**数据行数组**（不是节点）：

```js
{ type:'list', props:{
    items: items,
    actions: [                                  // 每个: {text, onClick}
      { text:'刷新',   onClick:'refresh' },
      { text:'全选',   onClick:'selectAll' },
    ],
    secondaryActions: [ { text:'更多操作', onClick:'moreAct' } ],
}}
```

### 6.2.5 下拉刷新与翻页

```js
const state = { files: [], loading: false, hasMore: false, loaded: false };

{ type:'list', id:'fileList', props:{
    items: state.files,
    refreshing: state.loading,        // 显示刷新转圈
    onRefresh: 'doRefresh',           // 用户下拉
    onEndReached: 'doMore',           // 滚到底
}}

$ui.on('doRefresh', () => load(true));
$ui.on('doMore',    () => load(false));

async function load(fresh) {
  if (!fresh && state.loaded && !state.hasMore) return;   // ⚠️ 必须自己判！
  state.loading = true; render();
  const list = await fetchPage(fresh ? 0 : state.files.length);
  state.hasMore = list.length === PAGE_SIZE;
  state.loaded  = true;
  state.files = fresh ? list : state.files.concat(list);
  state.loading = false; render();
}
```

**⚠️ `onEndReached` 必须自己判「还有没有下一页」** —— 基座只负责通知「滚到了」，
它不知道你的数据翻完没有。无条件翻页会导致「滑到底 → 空请求 → render → 滚动位置归零 → 跳回顶部」
（某个云盘应用 的真实 bug）。完整规则见 [10.5](10-页面栈与返回.md)。

### 6.2.6 more 菜单与长按多选

```js
// 行上挂 more
{ id:'f1', title:'a.mp4', onClick:'play',
  more: [ {text:'重命名', onClick:'ren'}, {text:'删除', onClick:'del'} ] }

// 事件
$ui.on('play', (e) => {
  const f = state.files.find(x => x.id === e.id);   // ⚠️ 用 e.id 回查
  if (f) play(f);
});
$ui.on('long', (e) => { state.selectMode = true; state.selId = e.id; render(); });
$ui.on('ren',  (e) => renameFile(e.id));
$ui.on('del',  (e) => deleteFile(e.id));
```

`more` 的事件 payload 同样带 `e.id`（0.1.19+）。

## 6.3 grid —— 图片网格

```js
{ type:'grid', props:{
    columns: 3,                    // 2~5 列
    items: [
      { id:'g1', title:'网格 1', subtitle:'副标题', url:'https://.../1.jpg', onClick:'g' },
      { id:'g2', title:'网格 2', url:'https://.../2.jpg', onClick:'g' },
    ],
    header: [ /* 冻结栏 */ ],
    footer: [ /* 冻结栏 */ ],
    onEndReached: 'doMore', onRefresh: 'doRefresh', refreshing: false,
}}
```

| 字段 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `columns` | number | — | 列数（2~5） |
| `aspect` | string | `4:3` | 封面宽高比：`"3:4"` / `"4:3"` / `"16:9"` / `"1:1"` |
| `items[]` | — | — | `{id,title,subtitle,url,onClick,onLongClick}` |
| `header`/`footer` | 节点数组 | — | 冻结栏 |
| `onEndReached`/`onRefresh`/`refreshing` | string/bool | — | 同 list |

**url 支持带 headers**：`{value:'...', headers:{Referer:'...'}}`

## 6.4 actions —— 操作按钮行

**既可以作为控件节点，也可以放进 `list.props.footer`。**

```js
// 独立控件
{ type:'actions', props:{ align:'fill', gap:8, items:[
    { text:'取消', onClick:'no' },
    { text:'确定', onClick:'ok' },
]}}
```

| 字段 | 值 | 说明 |
|---|---|---|
| `align` | `fill` / `left` / `center` / `right` | `fill` = 均分整行；其他 = 靠对应边 |
| `gap` | number | 按钮间距 |
| `items[]` | — | `{text, onClick}`；⚠️ 缺 `onClick` 会 warn「点了没反应」 |

## 6.5 table —— 表格

```js
{ type:'table', props:{
    bordered: true,
    stickyHeader: true,          // 长表格滚动时表头吸顶 (0.1.90+)
    onRowClick: 'rowClicked',    // 行点击事件 (0.1.90+)
    columns: ['名称', '大小', '状态'],
    rows: [
      ['Big Buck Bunny', '158MB', '✓'],                                    // 纯字符串
      ['Sintel Trailer',  '18MB',  { text: '⋯ 转码中', color: '#FFB300' }], // 对象单元格 (0.1.90+)
    ],
}}

$ui.on('rowClicked', (e) => {
  // e.id = 'r<下标>'，例如 'r1' 表示第 2 行
  const idx = parseInt(String(e.id).slice(1), 10);
  $app.toast('点了第 ' + (idx + 1) + ' 行');
});
```

| 字段 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `columns` | string[] | — | 表头 |
| `rows` | array[][] | — | 数据行，**每行列数须与 columns 对齐** |
| `bordered` | bool | false | 画 1dp 描边 |
| `stickyHeader` | bool | false | 表头吸顶（0.1.90+） |
| `onRowClick` | string | — | 行点击事件，`e.id = 'r<下标>'`（0.1.90+） |

### 单元格对象（0.1.90+）

单元格可以是字符串，也可以是对象 —— 用于「状态列按值标色」：

```js
{ text: '✓ 已完成', color: '#4CAF50', bold: true }   // align: 'left'|'center'|'right'
```

| 字段 | 类型 | 说明 |
|---|---|---|
| `text` | string | 单元格文字 |
| `color` | string | 文字颜色 |
| `align` | string | `left` / `center` / `right` |
| `bold` | bool | 加粗 |

⚠️ **表格是纯展示组件**，没有排序、列宽调整、单元格编辑 —— 移动端这些交互成本高收益低，
需要请自己在 `list` 上拼。

## 6.6 chart —— 数据图表

```js
{ type:'chart', props:{
    chartType: 'line',              // 'line' | 'area' | 'bar' | 'pie'
    title: '近7日收益',
    height: 220,
    unit: '%',
    labels: ['周一','周二','周三','周四','周五','周六','周日'],
    datasets: [
      { name:'005094', color:'#4FC3F7', data:[1.2,2.4,1.8,3.6,2.9,4.2,3.8] },
      { name:'003095', color:'#FFB74D', data:[0.8,1.1,2.0,1.6,2.8,3.0,2.5] },
    ],
    showGrid: true,
    showLegend: true,
}}
```

| 字段 | 类型 | 说明 |
|---|---|---|
| `chartType` | string | `line` / `area` / `bar` / `pie` |
| `labels` | string[] | X 轴（饼图=扇区名） |
| `datasets[]` | — | `{name, color, data[]}`，多系列叠加 |
| `height` | number | 高度 dp |
| `title` | string | 图表标题 |
| `unit` | string | 数值单位后缀 |
| `showGrid` | bool | 网格线 |
| `showLegend` | bool | 图例 |

**饼图**：单个 dataset，`data` 各项占总数比例：

```js
{ type:'chart', props:{
    chartType:'pie', title:'资产配置', height:230,
    labels:['基金','股票','债券','现金','其他'],
    datasets:[ { name:'配置', data:[40,25,20,10,5] } ],
}}
```

## 6.7 empty —— 空状态

```js
{ type:'empty', props:{ icon:'📦', text:'还没有数据' } }
```

| 字段 | 类型 | 说明 |
|---|---|---|
| `icon` | string | emoji 或文字 |
| `text` | string | 提示文案 |

**最佳实践**：列表/网格无数据时统一用它，而不是显示空白。

```js
function render() {
  $ui.render({ type:'root', props:{title:'收藏'}, children:[
    state.favs.length
      ? { type:'list', props:{ items: state.favs } }
      : { type:'empty', props:{ icon:'⭐', text:'还没有收藏，去列表页点♥' } },
  ]});
}
```

## 6.8 tree —— 树视图（0.1.90+）

### 什么时候用 tree

表达层级原来只有两条路，都有硬伤：

| 方案 | 问题 |
|---|---|
| `$ui.push` 一层层进 | 看不到整体结构，无法快速跳到深层节点 |
| 嵌套 `list` | 只能展现固定两级 |

`tree` 解决「展开收起 + 一眼看全貌」：文件管理器、目录树、设置分组、分类导航。

### 基本用法

```js
{ type:'tree', id:'fileTree', props:{
    onExpand: 'treeExpand',        // 点展开/收起箭头
    onRowClick: 'treeRow',         // 点整行
    onRefresh: 'treeRefresh',      // 下拉刷新（可选）
    refreshing: false,
    items: [
      { id:'d1', title:'📁 下载', icon:'📁', badge:'3', subtitle:'3 项',
        expanded: true,             // ⚠️ 受控：改这个值后必须 render
        onClick: 'treeRow',
        children: [
          { id:'f1', title:'a.mp4', subtitle:'158MB', onClick:'treeRow' },
          { id:'f2', title:'b.mp4', subtitle:'18MB',  onClick: 'treeRow' },
        ] },
      { id:'d2', title:'📁 音乐', icon:'📁', expanded: false,
        children: [ { id:'f3', title:'c.mp3', onClick:'treeRow' } ] },
    ],
}}
```

### 受控展开态

`expanded` 由**应用**维护，基座只回传事件。这是与 `switch`/`checkbox` 同一套模式 ——
基座不自己记状态，避免与应用数据不一致。

```js
$ui.on('treeExpand', (e) => {
  // e.id = 节点 id, e.expanded = 期望的新状态 (基座已取反)
  const node = findNode(state.tree, e.id);
  if (node) {
    node.expanded = !!e.expanded;
    render();                    // ⚠️ 必须 render，否则箭头不变
  }
});

function findNode(items, id) {
  for (const it of items || []) {
    if (it.id === id) return it;
    const hit = findNode(it.children, id);
    if (hit) return hit;
  }
  return null;
}
```

### items[] 字段

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | string | 事件回传 |
| `title` | string | 主标题 |
| `subtitle` | string | 副标题 |
| `icon` | string | 左侧 emoji |
| `badge` | string | 右侧徽标 |
| `right` | string | 右侧文字 |
| `expanded` | bool | 是否展开（受控） |
| `onClick` | string | 点整行 |
| `onLongClick` | string | 长按 |
| `children` | array | **递归**，同一契约的数据行 |

### 三条注意

1. **深度上限 10 层**，超出截断 —— 防失控嵌套把列表撑爆
2. **⚠️ 是 Lazy 组件**，不能放进 `root scroll:true`（与 `list`/`grid`/`tabs` 同规矩）
3. **`children` 写在 `items[]` 里，不是 `node.children`** —— 和 `list` 一样不读 node.children

## 6.9 skeleton —— 首屏加载占位（0.1.91+）

`list` / `grid` 的字段（不是独立控件）。items 为空且 `skeleton:true` 时渲染灰色假卡片。

```js
{ type:'list', props:{
    items: state.loading ? [] : state.items,   // 加载中传空数组
    skeleton: state.loading,                   // true = 显示占位
    skeletonCount: 5,                          // 占位卡片数 (list 1~20, grid 1~30)
}}
```

**为什么不做通用 skeleton 控件**：真正需要它的是「列表正在加载」这一刻，
而那一刻应用往往还没数据可渲染。做成字段，应用只要传 `skeleton:true` 就完事，
不需要自己拼 5 个假卡片再在数据到达时替换。

加载完成时把 `skeleton` 改 `false`（或直接渲染真实 items —— 两者只会有一个非空，不会叠加）。

## 6.10 列表页完整模板

```js
const state = { items: [], loading: false, hasMore: true, loaded: false, page: 0 };
const PAGE = 20;

function renderList() {
  $ui.render({
    type: 'root', props: { title: '我的列表' },
    children: [
      { type:'list', id:'mainList', props:{
          items: state.items,
          refreshing: state.loading,
          onRefresh: 'refresh',
          onEndReached: 'more',
          // ⚠️ 底部操作栏放 footer 里，不能与 list 平级
          footer: [
            { type:'actions', props:{ align:'fill', items:[
              { text:'添加', onClick:'add' },
              { text:'排序', onClick:'sort' },
            ]}},
            { type:'space', props:{ height:72 } },   // 给 fab 留位
          ],
      }},
      { type:'fab', props:{ text:'＋', onClick:'add' } },
    ],
  });
}

$ui.on('refresh', () => loadPage(true));
$ui.on('more',    () => loadPage(false));

async function loadPage(fresh) {
  if (!fresh && state.loaded && !state.hasMore) return;   // 硬性规则
  state.loading = true; renderList();
  try {
    const r = await $http.get(API + '?page=' + (fresh?0:state.page+1));
    const list = (r.json && r.json.items) || [];
    state.hasMore = list.length === PAGE;
    state.loaded  = true;
    state.page    = fresh ? 1 : state.page + 1;
    state.items   = fresh ? list : state.items.concat(list);
  } catch (e) {
    $app.toast('加载失败: ' + e.message);
  }
  state.loading = false;
  renderList();
}

$app.on('launch', () => loadPage(true));
```
