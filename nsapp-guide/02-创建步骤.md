# 第 2 章 · 创建步骤

从零创建一个 nsapp 的完整流程。分「新建 → 写 UI → 接数据 → 打包 → 安装」五步，
最后给一份**命令式清单**，可以直接照着敲。

---

## 2.1 方式 A：手机上新建（最快）

适合「想马上在手机上试试」的场景。

1. 基座启动器主界面 → **➕ 新建工程**
2. 填**应用 id**（小写连字符，如 `todo`）和名称
3. 基座自动生成骨架：
   ```
   apps/todo/
   ├── package.json     (自动填好 id/name/version/main/icon/apiVersion)
   ├── main.js          (可运行的 $app.on('launch') + $ui.render 示例)
   └── assets/icon.png  (默认图标)
   ```
4. 回启动器**长按刚生成的图标 → ✏️ 编辑** → 内置编辑器（CodeMirror，语法高亮）改代码
5. 顶栏 **▶ 保存并运行** → 立即重新拉起应用，改 `main.js` 马上生效

> ⚠️ 手机上新建/编辑的是**本机已安装应用**，要发给大家得另外打包推送（见 2.5）。
> ⚠️ 默认生成的是共用的占位图标，**上线前必须换成自己的**（见 12.2）。

---

## 2.2 方式 B：电脑上新建（推荐，可入版本库）

### 步骤 1：建目录与骨架

```bash
cd <仓库根目录>/apps
APP=my-app
mkdir -p $APP/assets
```

### 步骤 2：package.json

```bash
cat > $APP/package.json <<'EOF'
{
  "id": "my-app",
  "name": "我的应用",
  "displayName": "我的应用",
  "version": "1.0.0",
  "main": "main.js",
  "icon": "assets/icon.png",
  "description": "一句话说清楚这个应用干什么",
  "apiVersion": 1
}
EOF
```

### 步骤 3：图标

```bash
# 方式 1：基座自带生成器（256×256，纯 stdlib）
python3 server/make_app_icons.py my-app

# 方式 2：自己有图 → 转成 256×256 PNG
# convert my-logo.svg -resize 256x256 apps/my-app/assets/icon.png
```

**必须正方形**。非正方形在 64dp 方形槽位里会被 `ContentScale.Fit` 缩小，留大片空白。
切勿用 TV banner（320×180 横条）当图标。

### 步骤 4：main.js 骨架

先搭一个能跑的结构，再往里填控件：

```js
'use strict';

// ---------- 状态（模块级变量，应用运行期一直活着） ----------
const state = {
  loading: false,
  items: [],
};

// ---------- 工具 ----------
function pref(k, d) {
  const v = $prefs.get(k);
  return (v === undefined || v === null || v === '') ? d : v;
}
function withTimeout(p, ms) {
  return Promise.race([p, new Promise((_, rj) =>
    setTimeout(() => rj(new Error('请求超时')), ms))]);
}

// ---------- 渲染（每次状态变化都整棵重新描述） ----------
function render() {
  $ui.render({
    type: 'root',
    props: { title: '我的应用' },
    children: [
      state.loading
        ? { type: 'loading', props: { text: '加载中…' } }
        : { type: 'empty', props: { icon: '📦', text: '还没有数据' } },
    ],
  });
}

// ---------- 入口 ----------
$app.on('launch', () => {
  state.items = JSON.parse(pref('prefs.items', '[]'));
  render();
});

// ---------- 事件 ----------
$ui.on('refresh', () => { /* ... */ });
```

**为什么用 `state` + `render()` 模式**：UI 树是「声明式」的，你把状态映射成一棵完整的树，
基座负责把它画出来。不要试图「增量改某个控件」——那个抽象不存在。

### 步骤 5：语法检查

```bash
node --check apps/my-app/main.js && echo OK
```

## 2.3 写 UI（本章只给流程，控件细节在后四章）

按这个顺序搭界面最顺：

1. **定骨架**：`root` 容器 + 标题
2. **摆内容**：`card` / `column` / `row` 分组，`text` 做说明
3. **放交互**：`button` / `input` / `switch`，挂 `onClick` / `onChange` 事件名
4. **接事件**：`$ui.on('事件名', (e) => { 改 state → render() })`
5. **加页面**：`$ui.push(...)` 进详情/设置页

对照着抄：仓库内自带一个「全控件演示」示例应用（在 `apps/` 下找带 controls 字样的目录），
它的 `main.js` 就是全控件可运行示例。

## 2.4 接数据

**普通请求用 `$http`；播放用 `require('@shell/stream').url()`。**
（`$mhttp` 是出口代理版，**默认不要用**，只有用户明确要求走代理时才在那一处使用。）

```js
async function load() {
  state.loading = true; render();
  try {
    const r = await withTimeout(
      $http.get('https://api.example.com/list', { timeout: 15000 }), 15000);
    state.items = r.json || JSON.parse(r.body || '[]');
  } catch (e) {
    $app.toast('加载失败: ' + e.message);
  }
  state.loading = false;
  render();          // 别忘了重渲染，否则 UI 不更新
}
```

读用户输入：

```js
$ui.on('search', (e) => {
  state.keyword = e.value;      // 值控件事件带 e.value
  render();
});
```

存配置：

```js
$prefs.set('prefs.server', 'http://<服务器地址>');   // prefs. 前缀 → 重启保留
const srv = pref('prefs.server', '');                    // 读取要给默认值兜底
```

完整 API 见 [第 11 章](11-JS-API-详解.md)。

## 2.5 打包

```bash
cd <仓库根目录>/server
node pack.js
```

做的事：扫 `apps/` 下所有含 `package.json` 的目录 → 校验 `id`/`main` 存在 → `zip` 成一个
`.nsapp`（内容在 zip 根）→ 复制一份 `.zip` 别名 → 算 md5 → 写进 `data/built.json`。

```
server/data/apps/my-app.nsapp     # 安装包
server/data/apps/my-app.zip       # 同内容别名
server/data/built.json            # 清单（index.json 会合并它）
```

注意打包脚本会**自动排除**这些，防「包里有包」：
`*.nsapp` `*.zip` `*.nsapps` `*.DS_Store` `_*.js` `dist/*`

> 想只打某个应用，也可以手动：
> ```bash
> cd apps/my-app && zip -r -q ../my-app.nsapp . -x '*.nsapp' -x '*.zip'
> ```

### 想让商店立刻看到

`server.js` 的 `/index.json` 每次请求都会重新合并 `built.json`，所以 `node pack.js` 之后
**不用重启服务端**，手机商店页点「刷新」即可。

## 2.6 安装到手机（三个入口）

| 入口 | 做法 |
|---|---|
| **商店** | 基座 → 应用商店 → 填地址 → 刷新 → 点安装（最常用） |
| **文件** | 把 `.nsapp` 传到手机 → 点它 → 弹确认框（显示名称/版本/来源）→ 装 |
| **链接** | 浏览器打开 `nodeshell://install?url=<包地址>` 直装；或 `nodeshell://install?server=<商店地址>&id=<应用id>` |

---

## 2.7 升级已装的应用

1. 改代码，**`version` 必须递增**（如 `1.0.0` → `1.0.1`）
2. `node pack.js`
3. 手机商店页刷新 → 该应用显示「升级」→ 点

> ⚠️ version 不递增的话商店不会给升级按钮（基座按 versionName 判断）。
> ⚠️ 改了 `id` = 全新应用，与旧应用**共存**，不是升级。

## 2.8 完整命令清单（复制即用）

```bash
# 新建
cd <仓库根目录>/apps && mkdir -p my-app/assets

# 清单
cat > my-app/package.json <<'EOF'
{"id":"my-app","name":"我的应用","version":"1.0.0","main":"main.js","icon":"assets/icon.png","description":"一句话描述","apiVersion":1}
EOF

# 代码（写下最小可用版本）
cat > my-app/main.js <<'EOF'
$app.on('launch', () => {
  $ui.render({ type:'root', props:{title:'我的应用'}, children:[
    { type:'text', props:{text:'Hello', size:18, bold:true} },
    { type:'button', id:'btn', props:{text:'点我', onClick:'hi'} },
  ]});
});
$ui.on('hi', () => $app.toast('Hello!'));
EOF

# 图标
python3 server/make_app_icons.py my-app

# 检查 + 打包 + 起服务
node --check my-app/main.js
cd <仓库根目录>/server && node pack.js && node server.js
```
