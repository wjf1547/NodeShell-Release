## 13.1 调试器 Console

基座应用页顶栏右侧 **🛠 调试器** 按钮 → 底部弹出面板，两个页签：

| 页签 | 内容 |
|---|---|
| **Console** | 你的 `console.log`、UI 契约校验告警、应用 error |
| **Insight** | 运行状态/内存等 |

```js
console.log('载入完成, items =', state.items.length);
console.error('失败了', e.message);
```

**养成习惯**：每个事件 handler 的第一行、每次网络请求的返回，都 log 一行。
比盲猜快 10 倍。

## 13.2 UI 契约校验（0.1.64+）

基座在 `$ui.render`/`$ui.push` 时用 `ui-schema.json` 校验你的树，
**只报不拦**（warn 进 Console，不抛错）。

### 报什么

| 级别 | 场景 | 示例 |
|---|---|---|
| **ERR** | `type='list'` 写了 `node.children` | `❌ type='list' 不读 node.children → 子节点整块丢弃。list 的外围节点请写 props.header/footer/actions/secondaryActions` |
| **ERR** | `props.children` | `❌ type='card' 的 props.children 会被静默丢弃 → 子节点整块空白。children 必须写在【节点层】(与 props 平级), 不是 props 里` |
| **ERR** | 未知控件 type | `❌ 未知控件 type='textt' → 会渲染红色兜底卡片` |
| **ERR** | 节点缺 type | `❌ 节点缺 type` |
| **WARN** | 写了控件不读的 props 字段 | `⚠️ type='text' 不读 props.textAlign → 静默失效 (合法: align,bold,color,...)` |
| **WARN** | 数据行不读某字段 | `⚠️ type='list' 数据行不读 'onClickX' (合法: avatar,badge,icon,...)` |
| **WARN** | 按钮缺 onClick | `⚠️ 按钮 '确定' 缺 onClick → 点了没反应` |

### 为什么是「只报不拦」

若直接抛错，现有应用里所有已存在的静默失效写法会让它们当场起不来。
先让问题可见，逐批修完再考虑升级为拦截。

### 关掉

```js
$ui.setSchemaCheck(false);
```

（一般不用关。真有大量历史 warn 又不想看，再关。）

## 13.3 症状 → 根因对照表

| 症状 | 最可能的原因 | 去 |
|---|---|---|
| 按钮凭空消失 | `children` 写进了 `props.children` | [3.2](03-UI树基础.md) |
| 卡片整张空白 | 同上 | [3.2](03-UI树基础.md) |
| list 底部操作栏不显示 | `actions`/`footer` 写成了 `children` | [6.1](06-列表与集合控件.md) |
| 输入框不显示键入内容 | `value` 没绑 state，或没 `render()` | [第 7 章](07-输入与选择控件.md) |
| 开关/勾选回弹 | 改了 state 没 `render()` | [第 7 章](07-输入与选择控件.md) |
| 一滑到底就跳回顶部 | `onEndReached` 没判 `hasMore` | [10.5](10-页面栈与返回.md) |
| 返回键直接退出应用 | 进多层页用了 `render` 而非 `push` | [10.1](10-页面栈与返回.md) |
| 返回一下回两级 | 在 `back` 里又调了 `$ui.pop()` | [10.3](10-页面栈与返回.md) |
| 底栏被挤出屏幕点不到 | `actions` 与 `list` 平级，没进 `footer` | [6.2.3](06-列表与集合控件.md) |
| 页面崩/白屏 | `list`/`grid`/`tabs` 进了 `root scroll:true` | [3.5](03-UI树基础.md) |
| 红色兜底卡片 | `type` 拼错 | [第 4 章](04-控件速查表.md) |
| fab 点击没反应 | fab 写成顶层 key，或 onClick 是闭包 | [9.4](09-导航与页面控件.md) |
| fab 盖住最后一项 | footer 没加 `space` | [9.4](09-导航与页面控件.md) |
| 设置重启后丢 | 没写 `$prefs`，或键没带 `prefs.` 前缀 | [11.6](11-JS-API-详解.md) |
| 点了「删除」但其实没删 | 用 `.filter(x => x !== obj)` 比较引用 | [11.6](11-JS-API-详解.md) |
| 视频黑屏/播不了 | 容器不支持；看播放器浮层的错误码 | [8.3](08-展示与媒体控件.md) |
| 开全局代理后 API 403 | 用了 `$http` 以外的方式走了节点 | [11.4](11-JS-API-详解.md) |
| 打开是白屏 | 兜底打开了服务端不存在的页面 | [15.4](15-避坑清单.md) |

| 日志 | 位置 |

## 13.6 本地测试（无头）

应用侧想单测逻辑，可以把 `$http`/`$storage` 等 mock 成 `{}`，直接 `node` 跑：

```bash
node apps/<你的应用>/main.js    # 能跑通说明没有语法/顶层引用错误
```

更完整的做法是参考仓库内某些应用自带 `_test_*.js` 的形式：把桥接对象
mock 掉，用 `assert` 逐条校验纯函数。

## 13.7 真机验证清单

每次发布前，在真机上过一遍：

- [ ] 首屏 2 秒内出来（不是一直 loading）
- [ ] 每个按钮点过
- [ ] 每个输入框输过
- [ ] 返回键：首页 → 子页 → 再按（逐层退）
- [ ] 多选/浮层状态下按返回键（消费而非退出）
- [ ] 断网打开应用（有明确提示，不白屏）
- [ ] 弱网下拉刷新
- [ ] 播放一个视频 + 退出播放器
- [ ] 杀应用重进（配置还在）
- [ ] Console 里没有 ERR

## 13.8 让 AI 直接改这个应用（MCP，0.2.37+）

上面 13.1~13.7 是「人自己调」。0.2.37 起还有一条路：**把手机上的应用源码直接交给
外部 AI 客户端**（Claude Desktop / Cursor / Claude Code），让它自己「写 → 跑 → 读日志 → 改」。

手机端：**设置 → MCP 调试端点 → 打开「已开启」→ 保存并生效**（默认关，因为等于把
「往手机里写代码并执行」的权限交给能连上它的程序）。打开后设置页直接显示 MCP 地址与
Token，各带一个复制按钮。电脑端配置见 [`docs/MCP.md`](../../MCP.md)。

对写应用最有用的是那两个「以前只能靠人点」的工具：

| 工具 | 什么时候用 |
|---|---|
| `ns_get_docs` | **先调这个**。它返回控件表 + 四条铁律，不调就会编控件名 —— 而编错只渲染成灰卡片、**日志不报错** |
| `ns_send_event` | 改完点一下那个按钮，看界面是否真变（`uiChanged`）+ 日志里是否出现你的事件名 |
| `ns_get_state` | 除了树，还要看 **`schemaIssues`** —— 控件名写错时 `launchError` 是 null、日志不报错，只有这里会说「type='cardx' 不认识」（0.2.38+） |
| `ns_patch_file` | 改一个字符串**别整份重传**。只传 `old`/`new`，默认要求原文唯一命中；命中多处会拒绝并给行号（0.2.46+） |
| `ns_scan` | 交付前自查密钥。结果已脱敏；默认只扫应用源码，不扫 `node_modules`/`.trash`（0.2.46+） |
| `ns_purge_trash` | `ns_delete_file` 删掉的东西进 `.trash` 只会增，用这个倒掉。默认预演，`confirm:true` 才真删（0.2.46+） |

> **0.2.38 起「失败」长什么样**：`ns_write_file` 写完会先做语法检查，不过就
> `ok:false, written:false` + `syntaxError.line/source`，**文件不落盘**（不会给你留一份
> 坏代码）；启动崩了会给 `launchErrorDetail` 的行号；树有结构错误则 `ok:false` +
> `schemaIssues`。看到 `ok:false` 就去读那条错误，**不要重试同样的内容**。
> 另外 `ns_launch_app` 成功后**手机屏幕会同步切到那个应用** —— 你在电脑上看到的
> 和用户看到的是同一个界面。

> ⚠️ 不要拿它替代 13.7 的真机清单。它能验证「逻辑对不对」，验证不了「手感 / 字体 /
> 弱网」这些 —— 那些还得自己上手。
