## 8.1 text —— 文本

```js
{ type:'text', props:{
    text: 'Hello NodeShell',
    size: 14,              // 字号
    color: '#888',         // 颜色（#RGB/#ARGB/颜色名）
    bold: true,            // 加粗
    align: 'center',       // 'left' | 'center' | 'right'
    maxLines: 2,           // 最多行数
    expandable: true,      // 超出 maxLines 时显示「展开」
    rich: true,            // 0.1.68+ 行内 BBCode 富文本（默认开）
}}
```

### 行内富文本（0.1.68+）

```js
{ type:'text', props:{ text:
  '[b]粗体[/b] [i]斜体[/i] [u]下划线[/u] [c=#f60]橙色[/c] 普通文本' }}
```

| 标记 | 效果 |
|---|---|
| `[b]...[/b]` | 粗体 |
| `[i]...[/i]` | 斜体 |
| `[u]...[/u]` | 下划线 |
| `[c=#f60]...[/c]` | 指定颜色 |

**未知标记原样透传**，不会误伤 —— `[1080P]` 会正常显示为 `[1080P]`。
想关闭富文本：`rich: false`。

## 8.2 image —— 图片

```js
{ type:'image', props:{
    url: 'https://.../cover.jpg',
    height: 180,              // 固定高度(dp)
    maxHeightPct: 40,         // 无 height 时的高度上限(占屏高百分比, 默认40)
    contentScale: 'crop',     // 'crop' 裁剪填满 | 'fit' 等比完整显示
    gallery: true,            // 点击进大图浏览
    onClick: 'viewCover',
}}
```

**url 两种写法**：

```js
{ url: 'https://x/a.jpg' }                                    // 字符串
{ url: { value:'https://x/a.jpg', headers:{ Referer:'https://x/' } } }   // 带请求头
```

⚠️ `headers` 在 **url 对象内部**，不是顶层 props。

## 8.3 video —— 页内播放器

```js
{ type:'video', props:{
    url: 'https://.../BigBuckBunny.mp4',
    height: 200,                  // 固定高度(dp)
    title: '大雄兔',              // 播放器上方标题
    poster: 'https://.../p.jpg',  // 封面图
    resizeMode: 'fit',            // 'fit'(默认,保持比例) | 'fill'(铺满)
    playlist: [                   // 分集列表
      { title:'第1集', url:'https://.../1.mp4' },
      { title:'第2集', url:'https://.../2.mp4' },
    ],
}}
```

**0.1.83 起播放器带 ⛶ 放大按钮**：点击弹出全屏播放（同一实例不中断），可旋转/还原/关闭。

### 手势（迷你/全屏/页内 video 通用）

| 手势 | 效果 |
|---|---|
| 单击 | 控制条显隐（3.2s 自动隐藏） |
| 双击 | 播放/暂停 |
| 长按 | 倍速菜单（0.5×/1×/1.25×/1.5×/2×/3×） |
| 左右滑动 | 快进/快退（整宽 ≈ 10 分钟），中央浮层实时显示 |
| 全屏上下滑动 | 左半屏=亮度，右半屏=音量 |

### 支持的容器

基座 Media3 `DefaultExtractorsFactory` 自带：**HLS(m3u8) / mp4 / FLV**。
`.flv` 直播地址可直接传，**不需要 flv.js 或 WebView**。

### 用 video 控件还是 $media.open？

| 场景 | 用 |
|---|---|
| 内容里嵌一个视频，用户点了就播 | `video` 控件 |
| 点列表项 → 直接进播放，同时还能继续浏览 | `$media.open()`（迷你播放器，见 [11.3](11-JS-API-详解.md)） |

## 8.4 audio —— 页内音频条

## 8.5 webview —— 页内网页

```js
{ type:'webview', props:{
    url: 'https://example.com',
    height: 480,           // 默认 480dp
}}
```

**什么时候该用 webview，什么时候不该：**

| 场景 | 建议 |
|---|---|
| 第三方登录页 / OAuth 回调 | ✅ webview |
| 展示一段自己的 HTML | ✅ webview 或 `article` |
| 播放视频 | ❌ 用 `video` / `$media.open`（Media3 原生，支持 m3u8/mp4/flv） |
| 兜底「服务端某个页面」 | ❌ 服务端没有这种页面，会白屏（见 [15.4](15-避坑清单.md)） |

## 8.6 article —— 文章页

```js
{ type:'article', props:{
    title: '文章标题',
    image: 'https://.../cover.jpg',    // 顶部头图
    html: '<h2>正文</h2><p>支持任意 HTML 标签</p><pre><code>...</code></pre>',
}}
```

markdown 需要**应用层自己转 HTML**（可 `require` npm 的 `marked`）：

```js
const marked = require('marked');       // 需自带 node_modules
const html = marked.parse(mdSource);
```

## 8.7 button —— 按钮

```js
{ type:'button', id:'ok', props:{
    text: '确定',
    onClick: 'ok',
    variant: 'filled',       // 'filled'(默认) | 'tonal' | 'outlined' | 'text'
    fullWidth: true,         // 默认 true，占满整行
}}
```

| variant | 视觉 | 用途 |
|---|---|---|
| `filled` | 主色实底 | 主操作（确认/提交） |
| `tonal` | 主色浅底 | 次主操作 |
| `outlined` | 描边 | 取消/中性操作 |
| `text` | 纯文字 | 最低优先级（删除/更多） |

```js
// 一行两个按钮，取消+确定
{ type:'row', props:{ scroll:false, gap:8 }, children:[
  { type:'button', props:{ text:'取消', variant:'outlined', onClick:'no' } },
  { type:'button', props:{ text:'确定', onClick:'ok' } },
]}
```

## 8.8 progress —— 进度条

```js
{ type:'progress', props:{ value: 0.65, text: '进度 65%' } }    // 0~1
{ type:'progress', props:{ value: -1,  text: '加载中…' } }      // 负数 = 不定态
```

| 字段 | 类型 | 说明 |
|---|---|---|
| `value` | number | 0~1；**负数 = 不定态（转圈）** |
| `text` | string | 旁边文字 |

## 8.9 chip —— 筛选标签

```js
{ type:'row', props:{ gap:8 }, children:[
  { type:'chip', id:'c-all',   props:{ text:'全部', selected: state.filter===null,    onClick:'filter' } },
  { type:'chip', id:'c-video', props:{ text:'视频', selected: state.filter==='video', onClick:'filter' } },
  { type:'chip', id:'c-audio', props:{ text:'音频', selected: state.filter==='audio', onClick:'filter' } },
]}

$ui.on('filter', (e) => {
  state.filter = e.selected ? e.id.replace('c-','') : null;   // ⚠️ e.selected
  render();
});
```

| 字段 | 类型 | 说明 |
|---|---|---|
| `text` | string | 标签文字 |
| `selected` | bool | 是否选中态 |
| `onClick` | string | payload 带 **`e.selected`**（点击后的新状态） |

> ⚠️ `chip` 的 payload 是 `e.selected` 不是 `e.value`，别搞混。

## 8.10 icon —— 图标

```js
{ type:'icon', props:{
    name: '▶️',        // emoji 或文字
    size: 24,          // 字号(dp)
    color: '#4FC3F7',
    onClick: 'play',
}}
```

**没有图标字体库**，`name` 就是 emoji / 字符。想要彩色图标直接用 emoji。

## 8.14 loading —— 加载中

```js
{ type:'loading', props:{ text: '加载中…' } }    // text 可省略
```

**典型用法**：首屏数据未到位时占位。

```js
children: [
  state.loading
    ? { type:'loading', props:{ text:'加载中…' } }
    : { type:'list', props:{ items: state.items } },
]
```

## 8.15 组合示例：视频卡片

```js
function videoCard(v) {
  return { type:'card', children:[
    { type:'video', props:{
        url: v.url, height: 160, title: v.title, poster: v.cover,
        resizeMode: 'fit',
    }},
    { type:'row', props:{ gap:8, align:'center' }, children:[
      { type:'avatar', props:{ text: v.site[0], size: 32, shape:'rounded' } },
      { type:'column', props:{ gap:2 }, children:[
        { type:'text', props:{ text: v.title, size:13, bold:true, maxLines:1 } },
        { type:'text', props:{ text: v.site + ' · ' + v.duration, size:11, color:'#888' } },
      ]},
      { type:'badge', props:{ text: v.quality, color:'#4CAF50' } },
    ]},
    { type:'actions', props:{ align:'fill', items:[
      { text:'播放',   onClick:'play' },
      { text:'收藏',   onClick:'fav' },
    ]}},
  ]};
}
```
