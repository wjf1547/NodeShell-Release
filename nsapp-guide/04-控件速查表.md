# 第 4 章 · 控件速查表

全量控件一页速查。**字段名的权威来源是基座的控件定义**（本表由它生成，字段变更以基座实现为准）。

> 表中「数据行」指 `props.items` / `props.actions` / `props.datasets` 里的元素，它们是**普通数据对象**（没有 `type`），不是节点。
>
> 标 **0.1.90+** 的是新增控件（`tree` / `datepicker` / `segmented` / `sheet`）与增强字段
> （`table` 单元格对象化 + `onRowClick` / `search` 的 `filters` + `history`）。
>
> **0.1.91+** 新增：`timepicker` / `accordion`；增强：`input` 的 `min`/`max`/`step` +
> `type` 扩 email/tel/url、`list`/`grid` 的 `skeleton`/`skeletonCount`。
>
> **0.2.59+** 新增：`dialog`；增强：`text` 的 `selectable`/`copy`、`row` 的 `wrap`、
> `list` 的 `stickyHeader` + `items[].group`/`children`/`swipeActions` + `selectable` 多选、
> `chart` 的 `onClick`/`tooltip`、`image` 的 `qr`、`root` 的 `bottomBar`。
> 字段的权威来源是基座的控件定义（本表由它生成，字段变更以基座实现为准）。

## 4.1 容器 / 布局

| type | 主要字段 | 读 children? | 一句话 |
|---|---|---|---|
| `root` | `scroll`, `title`, `subtitle`, `id`, `bottomBar` | ✅ | 屏幕容器（顶栏标题）。`scroll:true` 时**不能**放 list/grid/tabs。**0.2.59+** `bottomBar` = 吸底节点数组（在滚动区之外，永不随内容滚动） |
| `card` | — | ✅ | 卡片容器（圆角/边框/底色），最常用的信息分组 |
| `column` | `gap`, `align`, `justify` | ✅ | 纵向布局；`gap` = 子节点间距(dp) |
| `row` | `align`, `gap`, `justify`, `scroll`, `weights`, `wrap` | ✅ | 横向布局。0.1.82 起 `scroll` 默认 `true`（横向滚动行）。**0.2.59+** `wrap:true` = 流式换行（标签墙首选，与 `scroll` 互斥，`wrap` 优先） |
| `space` | `height`, `width` | ❌ | 空白占位 |
| `divider` | — | ❌ | 分割线 |

## 4.2 列表 / 集合

| type | 主要字段 | 一句话 |
|---|---|---|
| `list` | `items`, `header`, `footer`, `actions`, `secondaryActions`, `onEndReached`, `onRefresh`, `refreshing`, `skeleton`, `skeletonCount`, `stickyHeader`, `selectable`, `selected`, `selectMode`, `onSelectChange` | 卡片列表 ⚠️**不读 children**，头/尾/操作栏全走 props；`skeleton` 首屏占位；**0.2.59+** `stickyHeader:true` 按 `items[].group` 分组吸顶；**0.2.59+** `selectable:true` 开多选（`selected`/`selectMode` 受控，不写则基座自管） |
| `grid` | `items`, `columns`, `aspect`, `header`, `footer`, `onEndReached`, `onRefresh`, `refreshing`, `skeleton`, `skeletonCount` | 图片网格（2~5 列），`skeleton` 首屏占位 |
| `tree` | `items`, `onExpand`, `onRowClick`, `onLongClick`, `onRefresh`, `refreshing` | 树视图，`items` **递归**，`expanded` 受控 ⚠️Lazy |
| `actions` | `items`, `align`, `gap` | 声明式按钮行：`{text, onClick}` |
| `table` | `columns`, `rows`, `bordered`, `onRowClick`, `stickyHeader` | 表格，单元格可为 `{text,color,align,bold}` 对象 |
| `chart` | `chartType`, `labels`, `datasets`, `height`, `title`, `unit`, `showGrid`, `showLegend`, `stacked`, `smooth`, `max`, `onClick`, `tooltip` | 图表，`chartType` **10 种**：line/area/bar/pie/radar/scatter/gauge/funnel/heatmap/treemap（详见 [06 章](06-列表与集合控件.md)）。**0.2.59+** `onClick` 点击取点、`tooltip`（默认 `true`，点了才显示，传 `false` 关闭） |
| `empty` | `icon`, `text` | 空状态占位 |

| `checkbox` | `checked`, `label` | `onChange` | 复选 |

| `dropdown` | `items`, `selected`, `placeholder` | `onChange` | 下拉选择 |
| `slider` | `value`, `min`, `max`, `step`, `label` | `onChange` | 滑块 |

## 4.4 展示 / 媒体

| `icon` | `name`, `size`, `color`, `onClick` | 图标（emoji/文字） |

## 4.6 数据行字段

### `list` 的 `items[]`

```js
{
  id: 'f1',                    // 事件回传
  title: '视频.mp4',           // 主标题
  subtitle: '128MB · 12:30',   // 副标题
  icon: '🎬',                  // 左侧图标（emoji）
  avatar: 'https://.../a.png', // 或头像 URL
  badge: '新',                 // 右侧徽标文字
  badgeColor: '#2E7D32',       // 徽标底色（不写 = 默认主题蓝）。⚠️ 不能传对象
  right: '128MB',              // 右侧文字
  more: [                      // 右侧 ⋯ 菜单
    { text: '重命名', onClick: 'ren' },
    { text: '删除',   onClick: 'del' },
  ],
  onClick: 'play',             // 点击事件名
  onLongClick: 'long',         // 长按事件名
  group: '本周',               // 0.2.59+ 分组名，配合 props.stickyHeader 吸顶
  swipeActions: [              // 0.2.59+ 左滑露出的操作按钮（每个 76dp 宽）
    { id: 'pin', text: '置顶', onClick: 'pin' },
    { id: 'del', text: '删除', onClick: 'del', color: '#E53935' },   // color 缺省 = 主题错误色容器
  ],
  children: [ /* 节点数组 */ ],  // 0.2.59+ 自定义整行布局（给了就不再用 title/icon 默认排布）
}
```

### `grid` 的 `items[]`

```js
{ id:'g1', title:'网格 1', subtitle:'副标题', url:'https://.../x.jpg', onClick:'g', onLongClick:'gl' }
```

### `tree` 的 `items[]`（递归，0.1.90+）

```js
{
  id: 'd1',                  // 事件回传
  title: '📁 下载',           // 主标题
  subtitle: '3 项',           // 副标题
  icon: '📁',                 // 左侧图标
  badge: '3',                 // 右侧徽标
  badgeColor: '#FFB300',      // 徽标底色（不写 = 默认主题蓝）
  right: '›',                 // 右侧文字
  expanded: true,             // 是否展开（受控，改后要 render）
  onClick: 'open',            // 点整行
  onLongClick: 'long',        // 长按
  children: [                 // ⚠️ 递归！里面还是同一契约的数据行
    { id: 'f1', title: 'a.mp4', onClick: 'open',
      children: [ { id: 'f1a', title: '更深一层', onClick: 'open' } ] },
  ],
}
```

深度上限 **10 层**，超出截断。

### ⚠️ 徽标的两个坑（实测踩过，写进文档不用再试）

1. **数据行的徽标颜色用 `badgeColor`，不是对象**。
   ```js
   // ✅ 对：文字与颜色是两个平级字段
   { id:'r1', title:'同步', badge:'成功', badgeColor:'#2E7D32' }
   // ❌ 错：badge 传对象会被 JSON 序列化成文本，直接显示成
   //    {"text":"成功","color":"#2E7D32"} 那一串
   { id:'r1', title:'同步', badge:{ text:'成功', color:'#2E7D32' } }
   ```
   徽标前景色由基座按底色亮度自动取黑/白，不用自己算。
2. **独立 `badge` 控件用 `color`**（不叫 `badgeColor`）：
   `{ type:'badge', props:{ text:'VIP', color:'#FFB300' } }`

```js
{ id: 'op1', title: '重命名', icon: '✏️', onClick: 'ren' }
```

### `dialog` 的 `actions[]`（0.2.59+）

字段与 `actions` 控件同源（都走 `ActionButton`）：

```js
{ id: 'cancel', text: '取消', onClick: 'dlgCancel' }
{ id: 'ok',     text: '确定', onClick: 'dlgOk', variant: 'filled' }   // variant 默认 tonal
```

`dialog` 是**受控**的：点取消/确定或点外部关闭，基座只发 `onChange`（`e.value = false`），
**必须自己把 `open` 置 false 再 `render()`**，否则会出现「关掉又弹回来」。
`dismissable:false` 时点外部与返回键都不关（危险操作确认用），只能走按钮。

### `actions` 的 `items[]`

```js
{ text: '确定', onClick: 'ok' }
```


### `radio` / `dropdown` 的 `items[]`

```js

```

```js

```

## 4.7 事件键全集

| 事件键 | 挂在哪 | payload |
|---|---|---|
| `onClick` | button / chip / icon / avatar / badge / link / fab / drawer item | `{id, ...}` |
| `onChange` | input / textarea / search / switch / checkbox / radio / dropdown / slider | `{id, value}` |
| `onChange` | `sheet` / `dialog`（受控关闭） | `{id, value:false}` |
| `onSelectChange` | `list`（0.2.59+ 多选） | `{id, selected:[...], count, mode}` |
| `onClick` | `chart`（0.2.59+ 点击取点） | `{index, label, values:[{name,value}]}` |
| `onSubmit` | input / search | `{id, value}` |
| `onLongClick` | list item / grid item | `{id}` |
| `more` | list item（点右侧 ⋯） | `{id}` |
| `onTabSelected` | tabs | `{index, prev}` |
| `onEndReached` | list / grid（滚到底） | `{id}` |
| `onRefresh` | list / grid（下拉刷新） | `{id}` |

## 4.8 媒体 URL 的两种写法

`image` / `video` / `audio` / `grid.item.url` 通用：

```js
// ① 字符串
{ url: 'https://x/a.mp4' }

// ② 带请求头（鉴权/防盗链源直接播）
{ url: { value: 'https://x/a.mp4', headers: { Referer: 'https://x/', Cookie: 'k=v' } } }
```

> `headers` 在 **url 对象内部**，不是顶层 props。
> 图片走 coil `ImageRequest`，播放器走 Media3 `requestHeaders`。
