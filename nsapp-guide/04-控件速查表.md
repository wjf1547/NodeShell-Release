# 第 4 章 · 控件速查表

全量控件一页速查。**字段名的权威来源是基座的控件定义**（本表由它生成，字段变更以基座实现为准）。

> 表中「数据行」指 `props.items` / `props.actions` / `props.datasets` 里的元素，它们是**普通数据对象**（没有 `type`），不是节点。
>
> 标 **0.1.90+** 的是新增控件（`tree` / `datepicker` / `segmented` / `sheet`）与增强字段
> （`table` 单元格对象化 + `onRowClick` / `search` 的 `filters` + `history`）。
>
> **0.1.91+** 新增：`timepicker` / `accordion`；增强：`input` 的 `min`/`max`/`step` +
> `type` 扩 email/tel/url、`list`/`grid` 的 `skeleton`/`skeletonCount`。
> 字段的权威来源是基座的控件定义（本表由它生成，字段变更以基座实现为准）。

## 4.1 容器 / 布局

| type | 主要字段 | 读 children? | 一句话 |
|---|---|---|---|
| `root` | `scroll`, `title`, `subtitle`, `id` | ✅ | 屏幕容器（顶栏标题）。`scroll:true` 时**不能**放 list/grid/tabs |
| `card` | — | ✅ | 卡片容器（圆角/边框/底色），最常用的信息分组 |
| `column` | `gap`, `align`, `justify` | ✅ | 纵向布局；`gap` = 子节点间距(dp) |
| `row` | `align`, `gap`, `justify`, `scroll`, `weights` | ✅ | 横向布局。0.1.82 起 `scroll` 默认 `true`（横向滚动行） |
| `space` | `height`, `width` | ❌ | 空白占位 |
| `divider` | — | ❌ | 分割线 |

## 4.2 列表 / 集合

| type | 主要字段 | 一句话 |
|---|---|---|
| `list` | `items`, `header`, `footer`, `actions`, `secondaryActions`, `onEndReached`, `onRefresh`, `refreshing`, `skeleton`, `skeletonCount` | 卡片列表 ⚠️**不读 children**，头/尾/操作栏全走 props；`skeleton` 首屏占位 |
| `grid` | `items`, `columns`, `aspect`, `header`, `footer`, `onEndReached`, `onRefresh`, `refreshing`, `skeleton`, `skeletonCount` | 图片网格（2~5 列），`skeleton` 首屏占位 |
| `tree` | `items`, `onExpand`, `onRowClick`, `onLongClick`, `onRefresh`, `refreshing` | 树视图，`items` **递归**，`expanded` 受控 ⚠️Lazy |
| `actions` | `items`, `align`, `gap` | 声明式按钮行：`{text, onClick}` |
| `table` | `columns`, `rows`, `bordered`, `onRowClick`, `stickyHeader` | 表格，单元格可为 `{text,color,align,bold}` 对象 |
| `chart` | `chartType`, `labels`, `datasets`, `height`, `title`, `unit`, `showGrid`, `showLegend` | 图表（line/area/bar/pie） |
| `empty` | `icon`, `text` | 空状态占位 |

## 4.3 输入 / 选择

| type | 主要字段 | 事件 | 一句话 |
|---|---|---|---|
| `input` | `value`, `placeholder`, `type`, `singleLine`, `disabled`, `min`, `max`, `step` | `onChange`, `onSubmit` | 单行输入，`type`=text/password/number/email/tel/url |
| `textarea` | `value`, `placeholder`, `rows` | `onChange` | 多行输入 |
| `search` | `value`, `placeholder`, `filters`, `history` | `onChange`, `onSubmit` | 搜索框，可带筛选 chip 与历史记录 |
| `switch` | `checked`, `label` | `onChange` | 开关 |
| `checkbox` | `checked`, `label` | `onChange` | 复选 |
| `radio` | `items`, `selected` | `onChange` | 单选组 |
| `dropdown` | `items`, `selected`, `placeholder` | `onChange` | 下拉选择 |
| `slider` | `value`, `min`, `max`, `step`, `label` | `onChange` | 滑块 |
| `datepicker` | `value`, `label`, `min`, `max`, `placeholder` | `onChange` | 日期选择器，`value` 为 `YYYY-MM-DD` |
| `timepicker` | `value`, `label`, `min`, `max`, `placeholder` | `onChange` | 时间选择器，`value` 为 `HH:mm`，支持跨天范围 |
| `segmented` | `items`, `selected` | `onChange` | 分段选择器（横排互斥 2~4 项） |

## 4.4 展示 / 媒体

| type | 主要字段 | 一句话 |
|---|---|---|
| `text` | `text`, `size`, `color`, `bold`, `align`, `maxLines`, `expandable`, `rich` | 文本。0.1.68+ 行内 BBCode 富文本 |
| `image` | `url`, `height`, `maxHeightPct`, `contentScale`, `gallery`, `onClick` | 图片 |
| `video` | `url`, `height`, `title`, `poster`, `resizeMode`, `playlist` | 页内播放器（0.1.83+ 有全屏按钮） |
| `audio` | `url`, `title`, `height`, `cover`, `resizeMode`, `playlist` | 页内音频条 |
| `webview` | `url`, `height` | 页内网页（默认高 480dp） |
| `article` | `html`, `title`, `image` | 文章页（WebView 渲染 HTML） |
| `button` | `text`, `onClick`, `variant`, `fullWidth` | 按钮（filled/tonal/outlined/text） |
| `progress` | `value`, `text` | 进度条，`value<0` → 不定态 |
| `chip` | `text`, `selected`, `onClick` | 筛选标签 |
| `icon` | `name`, `size`, `color`, `onClick` | 图标（emoji/文字） |
| `avatar` | `text`, `url`, `size`, `shape`, `onClick` | 头像 |
| `badge` | `text`, `color`, `onClick` | 角标 |
| `link` | `text`, `size`, `onClick` | 链接 |
| `loading` | `text` | 加载中指示 |

## 4.5 导航

| type | 主要字段 | 一句话 |
|---|---|---|
| `tabs` | `items`, `activeTab`, `onTabSelected`, `pages` | 底部标签页 ⚠️Lazy，须独占页面 |
| `topTab` | `items`, `activeTab`, `mode`, `onTabSelected` | 顶部标签页 |
| `drawer` | `items`, `header` | 抽屉导航（读 children） |

## 4.6 数据行字段

### `list` 的 `items[]`

```js
{
  id: 'f1',                    // 事件回传
  title: '视频.mp4',           // 主标题
  subtitle: '128MB · 12:30',   // 副标题
  icon: '🎬',                  // 左侧图标（emoji）
  avatar: 'https://.../a.png', // 或头像 URL
  badge: '新',                 // 右侧徽标文字
  right: '128MB',              // 右侧文字
  more: [                      // 右侧 ⋯ 菜单
    { text: '重命名', onClick: 'ren' },
    { text: '删除',   onClick: 'del' },
  ],
  onClick: 'play',             // 点击事件名
  onLongClick: 'long',         // 长按事件名
}
```

### `grid` 的 `items[]`

```js
{ id:'g1', title:'网格 1', subtitle:'副标题', url:'https://.../x.jpg', onClick:'g', onLongClick:'gl' }
```

### `tree` 的 `items[]`（递归，0.1.90+）

```js
{
  id: 'd1',                  // 事件回传
  title: '📁 下载',           // 主标题
  subtitle: '3 项',           // 副标题
  icon: '📁',                 // 左侧图标
  badge: '3',                 // 右侧徽标
  right: '›',                 // 右侧文字
  expanded: true,             // 是否展开（受控，改后要 render）
  onClick: 'open',            // 点整行
  onLongClick: 'long',        // 长按
  children: [                 // ⚠️ 递归！里面还是同一契约的数据行
    { id: 'f1', title: 'a.mp4', onClick: 'open',
      children: [ { id: 'f1a', title: '更深一层', onClick: 'open' } ] },
  ],
}
```

深度上限 **10 层**，超出截断。

### `segmented` 的 `items[]`

```js
{ id: 'list', label: '列表', icon: '▦' }     // icon 可选
```

### `sheet` 的 `items[]`

```js
{ id: 'op1', title: '重命名', icon: '✏️', onClick: 'ren' }
{ id: 'op2', title: '删除', icon: '🗑', destructive: true, onClick: 'del' }   //  destructive 用错误色
```

### `actions` 的 `items[]`

```js
{ text: '确定', onClick: 'ok' }
```

### `chart` 的 `datasets[]`

```js

```

### `radio` / `dropdown` 的 `items[]`

```js
{ id: 'a', label: '选项 A' }      // 事件回传 e.value = id
```

### `tabs` 的 `pages[]`

```js

```

### `topTab` 的 `items[]`

```js

```

### `drawer` 的 `items[]`

```js

```

## 4.7 事件键全集

| 事件键 | 挂在哪 | payload |
|---|---|---|
| `onClick` | button / chip / icon / avatar / badge / link / fab / drawer item | `{id, ...}` |
| `onChange` | input / textarea / search / switch / checkbox / radio / dropdown / slider | `{id, value}` |
| `onSubmit` | input / search | `{id, value}` |
| `onLongClick` | list item / grid item | `{id}` |
| `more` | list item（点右侧 ⋯） | `{id}` |
| `onTabSelected` | tabs | `{index, prev}` |
| `onEndReached` | list / grid（滚到底） | `{id}` |
| `onRefresh` | list / grid（下拉刷新） | `{id}` |

## 4.8 媒体 URL 的两种写法

`image` / `video` / `audio` / `grid.item.url` 通用：

```js
// ① 字符串
{ url: 'https://x/a.mp4' }

// ② 带请求头（鉴权/防盗链源直接播）
{ url: { value: 'https://x/a.mp4', headers: { Referer: 'https://x/', Cookie: 'k=v' } } }
```

> `headers` 在 **url 对象内部**，不是顶层 props。
> 图片走 coil `ImageRequest`，播放器走 Media3 `requestHeaders`。
