# 第 9 章 · 导航与页面控件

`tabs` / `topTab` / `drawer` / `fab`

---

## 9.1 tabs —— 底部标签页

最常见的主框架结构（类似微信底栏）。

```js
$ui.push({
  type:'root',
  props:{ title:'首页框架' },
  children:[
    { type:'tabs', id:'mainTabs', props:{
        activeTab: state.activeTab,          // 当前选中下标
        onTabSelected: 'tabChanged',         // 切换事件
        pages: [
          { title:'首页', icon:'🏠', children:[ /* 页1内容 */ ] },
          { title:'发现', icon:'🔍', children:[ /* 页2内容 */ ] },
          { title:'我的', icon:'👤', children:[ /* 页3内容 */ ] },
        ],
    }},
  ],
});

$ui.on('tabChanged', (e) => {
  state.activeTab = e.index;    // e.index = 新下标
  console.log('切换到', e.index, '原', e.prev);
});
```

| 字段 | 类型 | 说明 |
|---|---|---|
| `pages[]` | — | `{title, icon, children}` |
| `activeTab` | number | 当前选中下标 |
| `onTabSelected` | string | 切换事件，payload `{index, prev}` |

### ⚠️ tabs 是 Lazy 组件，必须独占页面

```js
// ❌ tabs 与其它内容平级放 scroll:true 的 root → 高度约束爆炸
{ type:'root', props:{ scroll:true }, children:[
  { type:'text', props:{ text:'标题' } },
  { type:'tabs', ... },
]}

// ✅ tabs 独占一个页面（push 出去），root 不 scroll
{ type:'root', props:{ title:'框架' }, children:[ { type:'tabs', ... } ] }
```

> `tabs` / `list` / `grid` 都是 Lazy 组件，**不能放进 `root scroll:true` 容器**。
> 见 [3.5](03-UI树基础.md)。

### 每个 page 的 children 怎么组织

```js
function homePage() {
  return {
    type:'root', props:{},
    children:[
      { type:'list', props:{ items: state.home, onEndReached:'more' } },
      { type:'fab', props:{ text:'＋', onClick:'add' } },
    ],
  };
}

const pages = [
  { title:'首页', icon:'🏠', children: homePage().children },
  { title:'我的', icon:'👤', children: minePage().children },
];
```

### 页签生命周期（0.1.25+）

切换页签会触发应用的 `activated` / `inactivated` 生命周期：

```js
$app.on('activated',   () => { /* 用户切到本应用 */ });
$app.on('inactivated', () => { /* 本应用被切走 */ });
```

## 9.2 topTab —— 顶部标签页

```js
{ type:'topTab', props:{
    mode: 'fixed',              // 'fixed' | 'scrollable'
    activeTab: state.tab,
    onTabSelected: 'topTabChanged',
    items:[
      { title:'推荐', children:[ /* 页1 */ ] },
      { title:'音乐', children:[ /* 页2 */ ] },
      { title:'视频', children:[ /* 页3 */ ] },
    ],
}}
```

**tabs vs topTab：**

| | tabs | topTab |
|---|---|---|
| 位置 | 底部 | 顶部 |
| 图标 | 支持 `icon` | 只有文字 |
| 语义 | 一级导航（不同功能模块） | 同模块内的分类切换 |
| 页面归属 | 通常独占一页 | 可嵌在页面中部 |

## 9.3 drawer —— 抽屉导航

```js
$ui.push({
  type: 'root',
  props: { title: '抽屉 demo' },
  children: [
    {
      type: 'drawer',
      props: {
        header: 'NodeShell 抽屉',      // 抽屉顶部标题
        items: [
          { id:'d-home',  title:'首页', icon:'🏠', onClick:'drawerItem' },
          { id:'d-music', title:'音乐', icon:'🎵', onClick:'drawerItem' },
          { id:'d-video', title:'视频', icon:'▶️', onClick:'drawerItem' },
          { id:'d-set',   title:'设置', icon:'⚙️', onClick:'drawerItem' },
        ],
      },
      // ⚠️ children 是【drawer 节点自己】的子节点，与它的 props 平级。
      //    写成 root 的 children 或 drawer.props.children 都会导致主内容区丢失。
      children: [                      // ← 主内容区
        { type:'text', props:{ text:'从屏幕左缘向右滑动可拉出抽屉', size:14, align:'center' } },
        { type:'list', props:{ items: mainItems } },
      ],
    },
  ],
});

$ui.on('drawerItem', (e) => {
  $app.toast('选中: ' + e.title);
  // 按 e.id 切换主内容区，然后 $ui.render(...) 刷新
});
```

**`drawer` 是少数既读 `props.items` 又读 `children` 的控件**：
- `props.items` = 抽屉菜单项（数据行）
- `children` = 主内容区（节点数组）
- ⚠️ `children` 必须与 `drawer` 的 `props` **平级**（挂在 drawer 节点上），
  不能写成 `props.children`（会被静默丢弃）

打开方式：**从屏幕左缘向右滑**。

## 9.4 sheet —— 底部动作面板（0.1.90+）

「点 ⋯ 弹出 3 个操作」这种高频交互的原生承载。

```js
{ type:'sheet', id:'fileSheet', props:{
    open: state.sheetOpen,          // ⚠️ 受控！由应用维护
    title: '选择操作',
    onChange: 'sheetClosed',        // 用户点空白处/下滑关闭时回传 value=false
    items: [
      { id:'ren',   title:'重命名', icon:'✏️', onClick:'doRename' },
      { id:'share', title:'分享',   icon:'📤', onClick:'doShare' },
      { id:'del',   title:'删除',   icon:'🗑', destructive: true, onClick:'doDelete' },
    ],
}}

// 打开
$ui.on('showSheet', () => { state.sheetOpen = true; render(); });

// 关闭（用户滑掉/点空白）—— 必须把 open 改回 false
$ui.on('sheetClosed', (e) => {
  state.sheetOpen = !!e.value;
  render();
});

// 点某一项（事件挂在 item 上，payload 带 item 的 id）
$ui.on('doDelete', (e) => { state.sheetOpen = false; render(); confirmDelete(e.id); });
```

| 字段 | 类型 | 说明 |
|---|---|---|
| `open` | bool | 是否展开。**受控**，必须自己维护 |
| `title` | string | 面板标题 |
| `items[]` | — | `{id, title, icon?, destructive?, onClick}` |
| `onChange` | string | 关闭时回传 `value=false` |

### ⚠️ 不维护 `open` 会「关了又弹回来」

基座弹层面板是**受控组件**：用户滑掉它只是「请求关闭」，真正的关闭要应用把 `open`
改 `false` 再 `render`。不处理 `onChange` 就会出现关不掉的怪事。

## 9.5 fab —— 悬浮按钮

```js
{ type:'fab', props:{
    text: '＋',           // 显示文字（emoji）
    icon: '＋',           // 可选，与 text 二选一
    onClick: 'add',
}}
```

**fab 是 children 数组里的节点，不是 tree 顶层 key。**

```js
// ❌ 常见错误：当成顶层字段
$ui.render({ type:'root', props:{...}, fab:{ text:'＋' } })       // 无效

// ✅ 放进 children
$ui.render({ type:'root', props:{...}, children:[
  { type:'list', props:{ items, footer:[ {type:'space',props:{height:72}} ] } },
  { type:'fab', props:{ text:'＋', onClick:'add' } },
]})
```

> `actions` / `fab` 都必须是 **children 数组里的节点**。有应用踩过这个坑。

**别忘了给 fab 留位置**：列表 `footer` 里加 `{type:'space',props:{height:72}}`，
否则 fab 会盖住最后一项。

## 9.6 主框架模板（tabs + 各页）

```js
const state = { tab: 0 };

// ---------- 各页内容 ----------
function homePage() {
  return { type:'root', props:{}, children:[
    { type:'list', id:'homeList', props:{
        items: state.home,
        onEndReached: 'homeMore', onRefresh:'homeRefresh', refreshing: state.homeLoading,
        footer:[ { type:'space', props:{ height:72 } } ],
    }},
    { type:'fab', props:{ text:'🔍', onClick:'goSearch' } },
  ]};
}

function minePage() {
  return { type:'root', props:{}, children:[
    { type:'card', children:[
      { type:'row', props:{ gap:12, align:'center' }, children:[
        { type:'avatar', props:{ text:'我', size:48 } },
        { type:'column', props:{ gap:4 }, children:[
          { type:'text', props:{ text:'本地用户', size:15, bold:true } },
          { type:'text', props:{ text:'ID: ' + $app.id, size:11, color:'#888' } },
        ]},
      ]},
    ]},
    { type:'space', props:{ height:12 } },
    { type:'card', children:[
      { type:'list', props:{ items:[
        { id:'set',  title:'设置',   icon:'⚙️', right:'›', onClick:'mine' },
        { id:'about',title:'关于',   icon:'ℹ️', right:'›', onClick:'mine' },
        { id:'exit', title:'退出',   icon:'🚪', onClick:'exit' },
      ]}},
    ]},
  ]};
}

// ---------- 主框架 ----------
function renderMain() {
  $ui.render({
    type:'root', props:{ title:'我的应用' },
    children:[
      { type:'tabs', id:'mainTabs', props:{
          activeTab: state.tab,
          onTabSelected: 'tabChanged',
          pages:[
            { title:'首页', icon:'🏠', children: homePage().children },
            { title:'我的', icon:'👤', children: minePage().children },
          ],
      }},
    ],
  });
}

$ui.on('tabChanged', (e) => {
  state.tab = e.index;
  // ⚠️ 切换页签不需要 render —— 基座自己切 page。
  //    但若页内容依赖 tab 状态，可在这里 render。
});
$ui.on('mine', (e) => {
  if (e.id === 'exit') $app.exit();
  else $ui.push({ type:'root', props:{ title:'设置', scroll:true }, children:[ /* ... */ ] });
});

$app.on('launch', renderMain);
```

## 9.7 常见错误

| 症状 | 原因 |
|---|---|
| tabs 页白屏/崩溃 | tabs 放进了 `root scroll:true` |
| tabs 切换后内容不更新 | 页 `children` 是渲染时的一次性快照；数据变了要重新 `$ui.render` 整棵 |
| fab 点了没反应 | `onClick` 写成闭包，或 fab 放在了顶层 key 而非 children |
| fab 盖住列表最后一项 | footer 里没加 `space` |
| drawer 拉不出来 | 从**屏幕左边缘**开始向右滑，中间起手无效 |
| drawer 主内容空白 | `children` 写进了 `props.children` |
| sheet 关不掉/关了又弹回来 | 没处理 `onChange` 把 `open` 改回 `false`（受控组件必须维护） |
| tree 箭头点了不变 | 改了 `expanded` 但没 `render()` |
| tree 深层节点报「节点缺 type」 | 把 `children` 写成了 `node.children`（应写在 `items[]` 里） |
