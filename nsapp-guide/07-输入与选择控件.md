# 第 7 章 · 输入与选择控件

`input` / `textarea` / `search` / `switch` / `checkbox` / `radio` / `dropdown` / `slider`

所有这一章控件都是**受控组件**：`value`/`checked`/`selected` 由你的 state 提供，
用户操作后通过 `onChange` 通知你 → 你改 state → `render()` → 新值生效。

```js
// 统一模式
const state = { name: '' };

{ type:'input', id:'name', props:{
    value: state.name,          // ← 受控值，必须与 state 绑定
    placeholder: '请输入',
    onChange: 'nameChanged',    // ← 事件名（字符串）
}}

$ui.on('nameChanged', (e) => {
  state.name = e.value;         // ← 取值
  render();                     // ← 重渲染，输入框才会显示你输入的字符
});
```

**不绑 `value` 的后果**：输入框不显示键入内容，或显示后立刻被清空。
**不 `render()` 的后果**：UI 与真实状态不一致（开关回弹、label 不更新）。

## 7.1 input —— 单行输入

```js
{ type:'input', id:'q', props:{
    value: state.q,
    placeholder: '搜索关键词',
    type: 'text',            // 'text' | 'password' | 'number'
    singleLine: true,        // 默认 true
    disabled: false,
    onChange: 'qChanged',
    onSubmit: 'qSubmit',     // 键盘「完成」时触发
}}
```

| 字段 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `value` | string | — | 受控值 |
| `placeholder` | string | — | 占位提示 |
| `type` | string | `text` | `text` / `password` / `number` |
| `singleLine` | bool | `true` | 关掉则变多行 |
| `disabled` | bool | `false` | 置灰不可编辑 |
| `onChange` | string | — | 每次输入，`e.value` = 当前文本 |
| `onSubmit` | string | — | 按键盘完成键，`e.value` = 当前文本 |

### 搜索框的典型用法

```js
{ type:'search', id:'q', props:{
    value: state.q, placeholder:'搜索', onChange:'qChanged', onSubmit:'qSubmit',
}}

$ui.on('qChanged', (e) => { state.q = e.value; });        // 输入过程只更新 state
$ui.on('qSubmit',  (e) => { state.q = e.value; doSearch(); });  // 回车才搜
```

> 用 `search` 还是 `input`？`search` 自带搜索图标和清除按钮，语义更清晰。

### filters 筛选 chip + history 历史记录（0.1.90+）

```js
{ type:'search', id:'q', props:{
    value: state.q, placeholder:'搜索视频',
    onChange: 'qChanged', onSubmit: 'qSubmit',
    // 横排筛选 chip：点选即搜索范围（可横向滚动，项多不挤爆）
    filters: [
      { id:'all',    label:'全部',   selected: state.filter === 'all' },
      { id:'video',  label:'视频' },
      { id:'audio',  label:'音频' },
    ],
    // 历史关键词行：点一下直接搜（走 onSubmit）
    history: state.history,       // ['大雄兔', 'Sintel']
}}

// filters 选中 → onChange 回传选中 id
$ui.on('qChanged', (e) => {
  state.filter = e.value;         // 'all' | 'video' | 'audio'
  render();
});
```

| 字段 | 类型 | 说明 |
|---|---|---|
| `filters[]` | — | `{id, label, selected}`；选中态由**应用**维护（受控），点选后 `onChange` 回传 `id` |
| `history[]` | string[] | 历史关键词，点击即触发 `onSubmit` |

**为什么不放在基座里管状态**：历史该存几条、要不要去重、筛选条件怎么和关键词组合，
全是业务决策，基座替应用决定必然有人不满意。所以基座只负责**展示 + 回传**。

## 7.2 textarea —— 多行输入

```js
{ type:'textarea', id:'note', props:{
    value: state.note,
    placeholder: '写点什么…',
    rows: 4,                 // 初始行数
    onChange: 'noteChanged',
}}
```

| 字段 | 类型 | 说明 |
|---|---|---|
| `value` | string | 受控值 |
| `placeholder` | string | 占位 |
| `rows` | number | 显示行数 |
| `onChange` | string | `e.value` = 全文 |

⚠️ **注意**：每次 `render()` 都会用 `value` 重置输入框内容。
如果用户输入过程中你就频繁 render（比如轮询刷新），会打断输入。
解决：**输入类控件只在用户主动提交/失焦时才 render**，或用 `singleLine` 的 input 做即时过滤。

## 7.3 switch —— 开关

```js
{ type:'switch', id:'sw-proxy', props:{
    label: '启用代理',
    checked: state.enabled,      // ⚠️ 布尔值，不是字符串
    onChange: 'switched',
}}

$ui.on('switched', (e) => {
  state.enabled = !!e.value;     // 强制转布尔
  $prefs.set('prefs.enabled', state.enabled);   // 立刻落盘
  render();                      // 刷新 label 等关联 UI
});
```

| 字段 | 类型 | 说明 |
|---|---|---|
| `label` | string | 开关旁文字 |
| `checked` | bool | 受控值 |
| `onChange` | string | `e.value` = 新布尔值 |

## 7.5 radio —— 单选组

```js
{ type:'radio', id:'quality', props:{
    selected: state.quality,      // 选中的 item.id
    items: [
      { id:'sd',   label:'标清 480P' },
      { id:'hd',   label:'高清 720P' },
      { id:'fhd',  label:'超清 1080P' },
    ],
    onChange: 'qualityChanged',
}}

$ui.on('qualityChanged', (e) => {
  state.quality = e.value;        // = 被选中的 id，如 'hd'
  render();
});
```

| 字段 | 类型 | 说明 |
|---|---|---|
| `items[]` | — | `{id, label}` |
| `selected` | string | 选中项的 `id` |
| `onChange` | string | `e.value` = 新选中的 `id` |

## 7.6 dropdown —— 下拉选择

```js
{ type:'dropdown', id:'server', props:{
    selected: state.serverId,                       // 选中 id，空=未选
    placeholder: '请选择服务器',
    items: servers.map(s => ({ id: s.id, label: s.name })),
    onChange: 'serverChanged',
}}
```

字段同 `radio`（`items` / `selected` / `placeholder` / `onChange`）。

**radio vs dropdown 怎么选：**

| 场景 | 用 |
|---|---|
| 选项 ≤ 4，用户要一眼看到全部 | `radio` |
| 选项多，或想省空间 | `dropdown` |

## 7.7 slider —— 滑块

```js
{ type:'slider', id:'vol', props:{
    label: '音量',
    min: 0,
    max: 100,
    step: 5,              // 步长
    value: state.volume,
    onChange: 'volChanged',
}}

$ui.on('volChanged', (e) => {
  state.volume = Number(e.value);    // e.value 可能是字符串，转数字
  $prefs.set('prefs.volume', state.volume);
  render();
});
```

| 字段 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `value` | number | — | 当前值 |
| `min` | number | — | 最小值 |
| `max` | number | — | 最大值 |
| `step` | number | — | 步长 |
| `label` | string | — | 左侧文字 |
| `onChange` | string | — | `e.value` = 新值 |

> `e.value` 的类型不保证，用 `Number(e.value)` 收一下最稳。

## 7.8 input 的范围约束与键盘类型（0.1.91+）

`type:'number'` 时可加 `min` / `max` / `step`：

```js
{ type:'input', id:'qty', props:{
    type: 'number',
    value: String(state.qty),
    min: 0, max: 100, step: 5,
    onChange: 'qtyChanged',
}}

$ui.on('qtyChanged', (e) => { state.qty = Number(e.value); render(); });
```

| 字段 | 类型 | 说明 |
|---|---|---|
| `min` / `max` | number | 范围下限/上限 |
| `step` | number | 步进，`onChange` 回传的值会**吸附到最近步进点** |

**软约束语义**（重要）：超出范围**不会拦你输入**（拦住会让用户输不进去又不知道怎么改），
而是「回传 clamp 后的值 + 输入框标红」。用户能看到自己输了什么，同时立刻知道超限了。

`type` 现在支持 6 种，区别只是弹哪种键盘（**基座不做格式校验**，那是应用侧的事）：

| type | 键盘 |
|---|---|
| `text` | 普通 |
| `password` | 普通 + 掩码 |
| `number` | 数字 |
| `email` | 邮箱（带 @ 键） |
| `tel` | 电话 |
| `url` | 网址（带 . / 键） |

## 7.9 datepicker —— 日期选择器（0.1.90+）

```js
{ type:'datepicker', id:'startDate', props:{
    value: state.date,              // 'YYYY-MM-DD'，空串 = 未选
    label: '开始日期',
    min: '2020-01-01',              // 可选范围下限
    max: '2030-12-31',              // 可选范围上限
    placeholder: '选择日期',        // 未选时的占位文字
    onChange: 'dateChanged',
}}

$ui.on('dateChanged', (e) => {
  // 确定 → e.value = '2026-10-20'
  // 取消/清除 → e.value = '' (空串，不是 null，不报错)
  state.date = e.value;
  render();
});
```

| 字段 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `value` | string | — | ISO 格式 `YYYY-MM-DD`，**空串 = 未选** |
| `label` | string | — | 左侧文字 |
| `min` | string | — | 可选范围下限（同 ISO 格式） |
| `max` | string | — | 可选范围上限 |
| `placeholder` | string | `选择日期` | 未选时的占位文字 |
| `onChange` | string | — | `e.value` = ISO 串；取消/清除回传**空串** |

**为什么 value 用 ISO**：应用侧 `new Date('2026-10-20')` 直接可用，不需要自己猜格式。
在此之前只能 `$ui.prompt` 让用户手输，`2026/1/1`、`2026-01-01`、`1月1日` 混在一起。

## 7.10 timepicker —— 时间选择器（0.1.91+）

```js
{ type:'timepicker', id:'openTime', props:{
    value: state.time,           // 'HH:mm' 24 小时制，空串 = 未选
    label: '营业时间',
    min: '09:00',                // 可选范围下限
    max: '22:00',                // 可选范围上限
    onChange: 'timeChanged',
}}

$ui.on('timeChanged', (e) => {
  state.time = e.value;          // '14:30'；取消/清除 → ''
  render();
});
```

| 字段 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `value` | string | — | 24 小时制 `HH:mm`，**空串 = 未选** |
| `label` | string | — | 左侧文字 |
| `min` | string | — | 可选范围下限 |
| `max` | string | — | 可选范围上限 |
| `placeholder` | string | `选择时间` | 未选时的占位文字 |
| `onChange` | string | — | `e.value` = `HH:mm`；取消/清除回传**空串** |

### 跨天范围

`min: '22:00'` + `max: '06:00'` 表示**通宵时段**（min > max），
凌晨 3 点算在范围内。bar / 便利店 / 网吧这类场景很常见。

## 7.11 segmented —— 分段选择器（0.1.90+）

```js
{ type:'segmented', id:'viewMode', props:{
    selected: state.mode,           // 选中项的 id
    items: [
      { id:'list', label:'列表', icon:'☰' },
      { id:'grid', label:'网格', icon:'▦' },
    ],
    onChange: 'modeChanged',
}}

$ui.on('modeChanged', (e) => { state.mode = e.value; render(); });
```

| 字段 | 类型 | 说明 |
|---|---|---|
| `items[]` | — | `{id, label, icon?}` |
| `selected` | string | 选中项的 `id` |
| `onChange` | string | `e.value` = 新选中的 `id` |

### segmented vs radio 怎么选

| | segmented | radio |
|---|---|---|
| 排法 | 横排互斥段 | 竖排单选组 |
| 适合 | **2~4 项**、高频切换 | 选项多、要一眼看全部 |
| 占位 | 省空间（一行） | 占整行、每项一行 |
| 典型 | 列表/网格切换、排序方式 | 画质、清晰度、主题 |

## 7.12 表单完整示例

```js
const state = { user: '', pass: '', remember: true, quality: 'hd' };

function renderLogin() {
  $ui.render({
    type:'root', props:{ title:'登录', scroll:true, id:'page-login' },
    children:[
      { type:'card', children:[
        { type:'column', props:{ gap:12 }, children:[
          { type:'input', id:'user', props:{
              value: state.user, placeholder:'用户名', onChange:'in' } },
          { type:'input', id:'pass', props:{
              value: state.pass, placeholder:'密码', type:'password',
              onChange:'in', onSubmit:'login' } },
          { type:'switch', id:'remember', props:{
              label:'记住我', checked: state.remember, onChange:'remember' } },
          { type:'button', id:'loginBtn', props:{ text:'登 录', onClick:'login' } },
        ]},
      ]},

      { type:'space', props:{ height:16 } },
      { type:'text', props:{ text:'画质偏好', size:13, color:'#4FC3F7', bold:true } },
      { type:'card', children:[
        { type:'radio', id:'quality', props:{
            selected: state.quality, onChange:'quality',
            items:[
              { id:'sd',  label:'标清' },
              { id:'hd',  label:'高清' },
              { id:'fhd', label:'超清' },
            ],
        }},
      ]},
    ],
  });
}

$ui.on('in', (e) => { state[e.id] = e.value; render(); });
$ui.on('remember', (e) => { state.remember = !!e.value; render(); });
$ui.on('quality', (e) => { state.quality = e.value; render(); });
$ui.on('login', async () => {
  if (!state.user || !state.pass) { $app.toast('请输入用户名和密码'); return; }
  try {
    const r = await $http.post(API + '/login', { user: state.user, pass: state.pass });
    if (r.json && r.json.ok) {
      $prefs.set('prefs.token', r.json.token);
      $app.toast('登录成功');
    } else {
      $app.toast('账号或密码错误');
    }
  } catch (e) {
    $app.toast('网络错误: ' + e.message);
  }
});

$app.on('launch', renderLogin);
```
